# توضيح مشكلة بيانات API

## المشكلة

API يرسل البيانات التالية:

```json
[
  {
    "id": 6,
    "category": null, // ← فارغ
    "categoryId": 1, // ← يحتوي على رقم الفئة
    "course": null, // ← فارغ
    "courseId": 3 // ← يحتوي على رقم الكورس
  }
]
```

## لماذا يظهر "دورات الإرشاد السياحي"؟

### السبب:

1. **API يرسل `categoryId: 1`** في جميع السجلات
2. **النظام يستخدم خريطة محلية** لتحويل الأرقام إلى أسماء:
   ```typescript
   const categoryLabels: { [key: number]: string } = {
     1: 'دورات الإرشاد السياحي', // ← هذا هو السبب
     2: 'دورات إدارة الفنادق',
     3: 'دورات السياحة',
     // ...
   };
   ```
3. **حقول `category` و `course` فارغة** في API

### التدفق:

```
API Response → categoryId: 1 → Local Mapping → "دورات الإرشاد السياحي"
```

## الحلول المقترحة:

### 1. حل فوري (مطبق حالياً):

- استخدام الخريطة المحلية لتحويل `categoryId` إلى أسماء
- إضافة تعليقات توضيحية في الكود

### 2. حل طويل المدى:

- طلب من فريق Backend إرسال أسماء الفئات في API
- إنشاء API منفصل للحصول على أسماء الفئات
- استخدام API endpoint مثل: `/api/Categories` للحصول على أسماء الفئات

### 3. حل بديل:

- عرض `categoryId` مباشرة بدلاً من الأسماء
- إضافة واجهة لإدارة أسماء الفئات

## مثال على API محسن:

```json
[
  {
    "id": 6,
    "category": "دورات الإرشاد السياحي", // ← اسم الفئة
    "categoryId": 1,
    "course": "مقدمة في الإرشاد السياحي", // ← اسم الكورس
    "courseId": 3
  }
]
```

## التوصية:

1. **مؤقتاً**: الاستمرار في استخدام الخريطة المحلية
2. **مستقبلاً**: التنسيق مع فريق Backend لإرسال أسماء الفئات والكورسات
3. **مراقبة**: التأكد من تحديث الخريطة المحلية عند إضافة فئات جديدة
