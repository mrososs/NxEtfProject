# 📚 LMS Project - Client Documentation

## 🎯 **نظرة عامة على المشروع**

مشروع LMS (Learning Management System) هو منصة تعليمية متكاملة تتيح للمستخدمين الوصول للدورات التدريبية والمحتوى التعليمي. تم تطوير النظام باستخدام Angular مع واجهة مستخدم حديثة ومتجاوبة.

---

## 🔄 **Flow النظام (User Journey)**

### **1. بداية التطبيق (Application Startup)**

```
1. فتح التطبيق
2. التحقق من المصادقة عبر API (/me)
3. إحدى الحالات التالية:
   ├─ ✅ مصادقة صحيحة → عرض الصفحة الرئيسية
   ├─ ❌ خطأ 401/403/500 → عرض صفحة الخطأ
   ├─ ❌ "No Profile Created" → توجيه لصفحة إنشاء الملف الشخصي
   └─ ❌ أخطاء أخرى → توجيه لموقع الاتحاد الرسمي
```

### **2. إنشاء الملف الشخصي (Profile Creation)**

```
1. الوصول لصفحة /profile
2. ملء البيانات المطلوبة:
   ├─ الاسم الأول والأخير
   ├─ الوصف الشخصي
   └─ صورة شخصية (اختياري)
3. حفظ البيانات عبر POST /me
4. تحديث الصفحة وعرض البيانات
```

### **3. استعراض الدورات (Course Browsing)**

```
1. الصفحة الرئيسية تعرض جميع الدورات
2. إمكانية البحث والتصفية:
   ├─ البحث بالعنوان
   ├─ تصفية حسب المستوى
   ├─ تصفية حسب المدرب
   ├─ تصفية حسب الفئة
   └─ تصفية حسب السعر
3. عرض النتائج في أقسام منفصلة
```

### **4. حماية الصفحات (Route Protection)**

```
- الصفحات المحمية تتطلب ملف شخصي
- عند محاولة الوصول لصفحة محمية:
  ├─ عرض dialog يطلب إنشاء ملف شخصي
  └─ زر للانتقال لصفحة إنشاء الملف الشخصي
```

## 🚧 **الميزات المطلوبة في Backend**

### **📝 نظام المدونات (Blogs System)**

```
الوظائف المطلوبة:
├─ GET /blogs - جلب جميع المدونات
├─ GET /blogs/{id} - جلب مدونة محددة
├─ POST /blogs - إنشاء مدونة جديدة
├─ PUT /blogs/{id} - تحديث مدونة
└─ DELETE /blogs/{id} - حذف مدونة

البيانات المطلوبة:
├─ العنوان (العربي/الإنجليزي)
├─ المحتوى (العربي/الإنجليزي)
├─ الصورة الرئيسية
├─ تاريخ النشر
├─ الكاتب
└─ التصنيفات
```

### **💳 نظام الدفع (Payment System)**

```
الوظائف المطلوبة:
├─ POST /payments/create - إنشاء عملية دفع
├─ GET /payments/{id} - جلب تفاصيل الدفع
├─ POST /payments/verify - التحقق من الدفع
├─ GET /payments/user - مدفوعات المستخدم
└─ POST /payments/refund - استرداد المدفوعات

البيانات المطلوبة:
├─ مبلغ الدفع
├─ نوع الدفع (بطاقة ائتمان، محفظة إلكترونية)
├─ تفاصيل الدفع
├─ حالة الدفع
└─ تاريخ الدفع
```

### **📊 نظام التقارير والإحصائيات**

```
الوظائف المطلوبة:
├─ GET /reports/courses - إحصائيات الدورات
├─ GET /reports/users - إحصائيات المستخدمين
├─ GET /reports/payments - إحصائيات المدفوعات
└─ GET /reports/analytics - تحليلات عامة
```

### **🔔 نظام الإشعارات**

```
الوظائف المطلوبة:
├─ GET /notifications - جلب الإشعارات
├─ POST /notifications/send - إرسال إشعار
├─ PUT /notifications/{id}/read - تحديد كمقروء
└─ DELETE /notifications/{id} - حذف إشعار
```
