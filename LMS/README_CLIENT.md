## 🔄 **كيفية استخدام النظام**

### **1. فتح التطبيق**

```
- النظام يتحقق من المصادقة تلقائياً
- إذا لم يكن لديك ملف شخصي، سيتم توجيهك لإنشاء واحد
```

### **2. إنشاء الملف الشخصي**

```
- املأ البيانات المطلوبة
- أضف صورة شخصية (اختياري)
- احفظ البيانات
```

### **3. استعراض الدورات**

```
- استخدم شريط البحث للبحث في الدورات
- استخدم الفلاتر للتصفية حسب المستوى، المدرب، الفئة
- انقر على أي دورة لعرض التفاصيل
```

### **4. الوصول للمحتوى المحمي**

```
- بعض الصفحات تتطلب ملف شخصي
- سيظهر dialog يطلب إنشاء ملف شخصي إذا لم يكن موجود
```
